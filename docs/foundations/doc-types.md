# Types of Documentation

Not all documentation is the same—and treating it as if it is leads to confusion.

One of the simplest ways to improve documentation quality is to choose the right type before writing.

---

## Why this matters

- Improves clarity and usability  
- Sets user expectations  
- Makes writing faster and more structured  
- Prevents content overlap  

---

## The four core types

A widely accepted model breaks documentation into four types:


Learn → Tutorial
Do → How-to
Lookup → Reference
Understand → Concept


---

## 1. Tutorials (Learning)

Used when:
- Users are new  
- They need guided learning  

Characteristics:
- Step-by-step  
- Outcome-focused  
- Beginner-friendly  

---

## 2. How-to guides (Doing)

Used when:
- Users want to complete a task  

Characteristics:
- Direct  
- Minimal explanation  
- Action-oriented  

---

## 3. Reference documentation (Looking up)

Used when:
- Users need specific information  

Characteristics:
- Structured  
- Detailed  
- Not meant to be read sequentially  

---

## 4. Conceptual documentation (Understanding)

Used when:
- Users need context  

Characteristics:
- Explanatory  
- Big-picture focused  

---

## The biggest mistake: mixing types

For example:
- A how-to guide with long explanations  
- A tutorial filled with reference tables  

This forces users to work harder.

---

## Practical guidance

Before writing, ask:

**Is the user trying to learn, do, look up, or understand?**

That answer determines everything.
